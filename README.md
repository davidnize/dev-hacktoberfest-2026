# DEV Hacktoberfest 2026 🎃

My projects for the DEV.to Hacktoberfest 2026 challenges. I finished Hacktoberfest as a Completionist++.

## Projects

- **between-us**: Between Us, a private diary for two people who live far apart. You each write entries and read each other's in one shared feed.
- **tonights-sky**: Tonight's Sky, a small web page that works out today's sunset and moon phase, then a local Gemma model (via Ollama) tells you when to step outside and look up.
- **pocket-ledger**: Pocket Ledger, a local-first expense log for freelancers. An open-weight AI model sorts each expense into a category and explains why.
- **sloth-cli**: Sloth, a lazy local AI command-line tool that tidies files and summarizes chats, built with Gemma, Ollama and GitHub Copilot (Week 3: Best Use of GitHub Copilot).

## Built with
HTML, CSS, JavaScript, Node.js, Ollama, Gemma and GitHub Copilot.
